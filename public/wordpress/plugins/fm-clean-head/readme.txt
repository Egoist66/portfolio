Removes unnecessary meta tags, emoji scripts, and generator links from wp_head.

== Description ==

* Disables WordPress emoji scripts and styles
* Removes RSD, WLW manifest, and shortlink tags
* Hides WordPress generator version in HTML

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` or install the ZIP via Plugins → Add New.
2. Activate the plugin through the 'Plugins' menu in WordPress.
