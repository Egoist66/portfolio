A collection of 7 powerful Gutenberg blocks built for modern WordPress sites.

== Description ==

ContentBlocks adds 7 beautiful, high-performance Gutenberg blocks to your WordPress editor. Each block uses server-side rendering for optimal front-end speed and SEO.

Blocks included:
* **Hero** — Full-width hero section with title, subtitle, CTA button, background color, and overlay
* **Testimonials** — Carousel with star ratings, avatar, name, position, and autoplay
* **Pricing Table** — Responsive pricing grid with popular badge, features list, and CTA
* **FAQ Accordion** — Expandable Q&A with smooth open/close animation
* **Team Members** — Grid with photo, name, position, bio, and social links
* **Stats Counter** — Animated number counters with IntersectionObserver
* **Timeline** — Vertical timeline with date, title, and description

== Installation ==

1. Upload the `content-blocks` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Find the blocks in the Gutenberg editor under the "ContentBlocks" category

== Frequently Asked Questions ==

= Do the blocks work with any theme? =
Yes. The blocks include their own styles and work with any modern WordPress theme.

= Are the blocks editable on the front-end? =
No, all blocks are edited within the Gutenberg editor and rendered server-side.
