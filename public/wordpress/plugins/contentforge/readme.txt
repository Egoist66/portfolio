Content construction toolkit — UI for custom post types, meta fields, shortcodes, and template overrides.

== Description ==

ContentForge lets you build WordPress content structures entirely from the admin UI — no code required.

**Post Types** — Create and manage custom post types with a visual form. Configure labels, visibility, archive, supports, rewrite rules, and menu icons.

**Custom Fields** — Define groups of meta fields and attach them to any post type. Supported types: text, textarea, WYSIWYG, URL, email, number, checkbox, select, image (with media library), and color picker.

**Shortcodes** — Create two types of shortcodes:
* Static HTML — embed any HTML content with nested shortcode support
* Dynamic — query posts with a configurable template using placeholders: {title}, {excerpt}, {content}, {date}, {permalink}, {thumbnail}

== Installation ==

1. Upload `contentforge` to `/wp-content/plugins/`
2. Activate via Plugins screen
3. Find ContentForge in the admin menu
