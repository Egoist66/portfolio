Enables safe SVG uploads in the WordPress media library.

== Description ==

* Allows SVG mime type in Media Library
* Restricts uploads to users with upload_files capability
* Strips script tags from uploaded SVG content

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` or install the ZIP via Plugins → Add New.
2. Activate the plugin through the 'Plugins' menu in WordPress.
